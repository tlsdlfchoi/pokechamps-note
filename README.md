# 오레오거폰

포켓몬 챔피언스용 개인 웹 앱 — 샘플·파티 저장, 데미지 계산기, 내구 역산, 도감, 랭크배틀 채용률.

- 앱 주소: https://tlsdlfchoi.github.io/pokechamps-note/
- 저장한 샘플·파티·그림은 각자 기기(브라우저)에만 저장돼요.
- Battle data provided by [Pokémon Champions Battle Data](https://pokemonbattledata.pages.dev).
- Damage calculation: [@smogon/calc](https://github.com/smogon/damage-calc) (MIT). Korean names: [PokeAPI](https://github.com/PokeAPI/pokeapi).
